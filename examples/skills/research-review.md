# research-review — Synthetic Example Skill

**Purpose:** Review supplied project materials and produce a concise recommendation.

## Use when
- the user asks to review evidence or documents;
- the output is a short recommendation or issue summary.

## Do not use when
- the request is only formatting or translation;
- the task requires a domain-specific professional opinion not covered by the project.

## Method
1. Read only the sources permitted by the project instructions.
2. Separate source-supported facts from assumptions and unresolved items.
3. Identify the material findings that can change the recommendation.
4. Produce the requested recommendation in the project output format.
5. If a configured decision gate is triggered, return the work to that gate rather than inventing approval.

## Output
- conclusion;
- key evidence;
- material gaps;
- recommendation;
- gate trigger, if any.

## Boundary
This is a synthetic example method. It does not create approval, professional authority, or permission for external action.
