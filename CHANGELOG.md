# Changelog

## v1.0 — Initial public baseline

APOS v1.0 publishes the **Markdown Project Profile** as the single public reference profile for the initial release.

The public profile uses four core operational components:

- `PROJECT_INSTRUCTIONS.md`
- `ORCHESTRATOR.md`
- `DECISION_GATES.md`
- `skills/`

with `PROJECT_STATE.md` as a lightweight supporting continuity mechanism.

Before publication, internal draft packaging used additional configuration, handoff, and record-template files. Those drafts were not public baselines and are superseded by this v1.0 reference profile. This selection changes the **reference-profile surface**, while preserving the underlying APOS-I1–I8 invariants and authority boundaries documented in the specification.

The public repository therefore presents one v1.0 baseline, not two competing profiles.
