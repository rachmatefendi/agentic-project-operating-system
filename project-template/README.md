# APOS Project Template

Copy these files into your LLM Project/workspace.

Start with:

1. `PROJECT_INSTRUCTIONS.md`
2. `ORCHESTRATOR.md`
3. `DECISION_GATES.md`
4. `skills/SKILL_TEMPLATE.md`

Use `PROJECT_STATE.md` only when the project needs continuity across sessions.

Delete unused placeholders and add only the skills/gates your project actually needs.
